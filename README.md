# Context7

**Context7** is an open-source Model Context Protocol (MCP) server and developer tool built by Upstash that pulls up-to-date, version-specific library documentation and code examples directly into AI coding assistants. It prevents AI models from hallucinating outdated APIs by injecting real-time docs straight into your prompt's context.

## Key Benefits

* **Live, Version-Specific Docs:** Fetches current official documentation instead of relying on stale model training data.
* **Accurate Code Examples:** Provides real, working code snippets tailored to the exact framework version you use.
* **Broad Tool Support:** Integrates cleanly with OpenCode, Cursor, Claude Code, Windsurf, and other MCP-compatible editors.
